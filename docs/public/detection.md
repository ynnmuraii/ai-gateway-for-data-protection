# Какие данные распознаёт Контур

[Вернуться к описанию продукта](../../README.md).

| Категория | Поддержка | Начальное действие |
| --- | --- | --- |
| API_KEY | AWS AKIA/ASIA, поддерживаемые sk-ключи, GitHub и Slack | BLOCK |
| ACCESS_TOKEN | Токены с распознаваемым контекстом bearer/token | BLOCK |
| JWT | Поддерживаемый формат JSON Web Token | BLOCK |
| EMAIL | Email через Presidio и дополнительные проверки границ | MASK |
| PHONE | Телефоны RU, US и GB | MASK |
| IP_ADDRESS | IP-адреса из зафиксированных защищаемых CIDR | MASK |
| INTERNAL_HOSTNAME | Имена в `.internal`, `.corp`, `.local` и корпоративных словарях | MASK |

Администратор может изменить действие для любой категории. BLOCK имеет приоритет над MASK и ALLOW. Распознавание ключа не проверяет, действителен ли он у провайдера.

Если найденные фрагменты с действием MASK вложены друг в друга, заменяется внешний фрагмент: например, у `admin@db.internal` скрывается весь email вместе с внутренним доменом. В журнале учитываются обе найденные категории. BLOCK по любой категории по-прежнему останавливает запрос целиком; частично пересекающиеся диапазоны и одинаковые диапазоны разных категорий остаются техническим отказом.

Публичный IP не считается конфиденциальным только из-за своего формата. Защищаемые диапазоны фиксируются в профиле детектора; отдельного UI-редактора CIDR нет. Опубликованные словари и политики неизменяемы: изменения создают новую версию.

При маскировании используется HMAC-маркер, привязанный к интеграции, личности и диалогу. Повторяющееся найденное значение получает ту же замену в своей области. Исходные значения и обратный словарь в базе не хранятся; ответ модели автоматически не восстанавливает оригиналы.

spaCy-пакеты RU/EN загружаются локально в режиме tokenizer-only: выбранным распознавателям Presidio не требуется NER. Выбранный профиль и версии зависимостей входят в проверяемый bundle/checksum.

## Ограничения

Кодирование, необычные символы, разнесённые секреты, неизвестные форматы и восстановление личности по оставшемуся контексту могут обходить фильтрацию. Набор проверяемых категорий не означает обнаружение всех персональных данных. Ответ провайдера DLP-проверку не проходит.

Для знакомства с приложением используйте синтетические значения. Воспроизводимые проверки и ограничения тестового корпуса описаны в [инструкции разработчика](development.md).
