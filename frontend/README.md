# Панель администратора

React + TypeScript + Vite. Русскоязычная панель администратора: обзор, безопасный журнал, preview, версии политик и словарей, пользователи, интеграции, параметры провайдера и хранения. API: `/admin/api`; обработчики и модели запроса находятся в `backend/gateway/control.py`, preview — в `backend/gateway/routes.py`. Публичная страница OpenAPI на шлюзе отключена.

Требуется Node.js 22.20+ и npm.

```powershell
npm ci --cache .npm-cache
npm run dev
```

Откройте `http://127.0.0.1:5173/admin/`. Vite перенаправляет `/admin/api` и `/health` на локальный сервер `127.0.0.1:8000`. Для cookie и проверки Origin используйте одну согласованную точку входа панели и API; в production панель обслуживается шлюзом по `/admin/`.

```powershell
npm test
npm run build
```

Готовые статические файлы находятся в `dist/`; ссылки на ресурсы начинаются с `/admin/`.

Сессия хранится в HttpOnly cookie сервера. CSRF-токен, текст проверки, пароли, значения словаря и однократно показанные ключи хранятся только в памяти страницы. Панель не использует localStorage/sessionStorage и не подключает внешние шрифты, аналитику или CDN. Ошибки выводятся через фиксированные безопасные сообщения; исходные тела ошибок не показываются.

Публикация политики отделена от активации. При активации и изменении провайдера отправляется `If-Match`; конфликт сохраняет сообщение об ошибке и требует обновления данных. В списке профилей доступны только установленные сервером версии детектора. Старый профиль S1 можно просмотреть и заменить в новом черновике.

Поиск записей словаря выполняется в памяти панели. Изменение опубликованных значений создаёт новый черновик. Поиск и страницы не исключают скрытые записи из сохраняемого набора.

Браузерная проверка запущенного стенда выполняется из корня проекта:

```powershell
npm install --prefix .runtime/browser-tools playwright
$env:GATEWAY_BROWSER_URL = 'http://localhost:8080/admin/'
$env:GATEWAY_ACCESS_FILE = (Resolve-Path .runtime/compose-access.json).Path
node scripts/browser-smoke.cjs
```

Нужен установленный Google Chrome. JSON с доступом содержит `admin_username` и `admin_password`; он остаётся в `.runtime`, вне Git. Проверка использует синтетические примеры всех семи категорий, открывает экраны и проверяет модальное окно и мобильную ширину. Скриншоты и результат сохраняются в `.runtime/sprint-2-browser/`; пароли и ключи не снимаются.
